# Interactive 3D Kit

Explore a PROVES 1U CubeSat in your browser. Drag to orbit, scroll or pinch to zoom, and use the **Explode** slider to pull the kit apart. Click any part, or pick it from the parts list, to learn what it does.

Press **Build** for a step-by-step build guide. Each step shows the parts that go on next, in the order the kit is assembled. Use **Next** and **Back**, or the arrow keys, to move between steps.

!!! note "About the model"
    The model is the *PROVES - Electra* flight assembly, exported from Onshape and simplified for the web. The flight controller is a placeholder shape, and fine detail such as PCB traces is reduced. To link straight to a part, add `?part=<id>` to the full-screen URL, for example `viewer.html?part=battery-board`. To open the build guide at a step, add `?step=<number>`, for example `viewer.html?step=5`.
