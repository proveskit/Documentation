## Utilized Parts
The Z- solar panel implements the same elements as the [XY solar board](XY_solar_board.md):

| Function | Part | Qty | Interface |
| -------- | ---- | --- | --------- |
| Solar cells | AnySolar KXOB101K08TF | 6, in 2s3p | VSolar |
| Temperature sensor | Microchip MCP9808T-E/MC | 1 | I2C |
| Magnetorquer drivers | TI DRV2605LDGSR haptic motor driver | | I2C |
| Ambient light sensor | Vishay VEML7700-TT | | I2C |
| Power indicator | Blue LED | 1 | |
| Connector | 5-pin Molex 1.5mm pitch Picolock | 1 | VSolar, 3.3V, I2C |
